# Football Player Database System  

This project is a simple **Football Player Database System**, featuring **five football clubs**, each with **five players**. The system allows users to perform various operations such as **searching for players and clubs, adding new players**, and more.  

## Part 1: Console-Based Implementation  
[Part 1](https://github.com/MubasshiraMusarrat/CSE-108-Football_Player_Database_System/tree/main/project-1) of the project implements the core features of the **Football Player Database System** ([detailed in this PDF](https://github.com/MubasshiraMusarrat/CSE-108-Football_Player_Database_System/blob/main/Football%20Player%20Database%20System.pdf)) using **basic Java programming**. This version operates entirely via the **console**, where users can test and interact with the system.  

## Part 2: JavaFX-Based UI with Server-Client Networking  
[Part 2](https://github.com/MubasshiraMusarrat/CSE-108-Football_Player_Database_System/tree/main/project-2) enhances the project by integrating a **graphical user interface (GUI)** using **JavaFX**, an external Java library. The JavaFX library was downloaded and configured in the **VM machine settings**, and the project's run configuration was modified to support **multiple instances** of the main file. The UI design was created using **Scene Builder**. You can refer to any **YouTube tutorial** to learn how to use JavaFX, Scene Builder, and run multiple instances simultaneously.  

Additionally, a **server-client networking system** was implemented using **Java socket programming**. In this setup, the **database acts as the server**, while the **football clubs function as clients**. Multiple club instances can be run at the same time, enabling **real-time player transfers** between clubs. This networking feature enhances the project by allowing users to **buy and sell players dynamically**, with all changes immediately visible across connected instances.
